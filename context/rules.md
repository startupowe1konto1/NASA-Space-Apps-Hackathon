## Facts from the Participant FAQs

| Topic | Rule |
|---|---|
| Dates | Event runs 14–15 Nov 2026. Each Local Event sets its own end time; submit by that time. |
| Theme | "The Next Frontier" |
| Work before the event | Teams are not allowed to begin working on the challenges before the hackathon. |
| Team size | Max 6 members. Local Event teams: min 1. Universal Event teams: min 2 for global judging. One team per person, one challenge per team. |
| Submission | Through the team's project page on spaceappschallenge.org (required for global judging). Step-by-step in the Project Submission Guide (published 13 Nov). |
| AI ("Super Intelligence", SI) | Allowed. Each submission must include a description of how SI/AI tools were used in developing the project. |
| Under 18 | Registered and accompanied by a parent/guardian; no photos, video, voices or likeness of minors in the project or submission. |
| Judging | After the event by NASA, Space Agency Partners and industry experts. Criteria in the Judging and Awards Guide (published 13 Nov). Nominees/finalists Dec 2026, winners Jan 2027. |
| Conduct | Local Lead or conduct@spaceappschallenge.org |
