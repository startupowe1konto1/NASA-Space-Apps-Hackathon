# Steps 0–4 (O1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A start page, the field step before the goal step, step 7 and the share link removed, the field outlined straight from the address search, and a readable priorities step.

**Architecture:** The store keeps one ordered list of step keys and decides "can continue" by key, not by number, so the order can change without touching the steps. Step 0 is the start page: no progress bar and no footer. A search hit goes through the same `addFieldAt` as a map tap; near the Iowa demo field it returns the stored demo outline, in Poland the ULDK parcel, elsewhere the 4 ha square.

**Tech Stack:** React 18, TypeScript, Zustand, Tailwind, Leaflet, Vitest + Testing Library, Playwright.

**Spec:** `HANDOFF-frontend.md` v2 (the user's decisions per step), with the user's answers of Sat 14 Nov, 23:10: steps 0–4 are O1's; the Iowa field may be outlined by hand, but in the animation the search must fit the field by itself; step 7 goes together with the share link; steps 5 and 6 are O3's and O4's.

## Global Constraints

- TDD: test, red, code, green. UI tests wait for specific text (`findByText`/`waitFor`), not just the element.
- Tests never hard-code values that come from fixtures: read areas, names and ids from `demoFields`.
- Every screen keeps its loading, offline, no-data and error states.
- UI text lives in `messages/en.json` and `messages/pl.json` next to the code; every new key gets both (the i18n parity test checks ids). English text goes through anti-ai-writing.
- Before each PR: `git fetch && git rebase origin/main && npm run typecheck && npm run test && npm run build && npm run validate:data`, then `npx playwright test` (e2e runs only on O1's laptop) and a look at `localhost` in EN and PL at 375 px.
- PR titles start with the task id (O1-F1, O1-F2, O1-F3). Merge after a green `ci` on a branch up to date with `main`, with `--match-head-commit`.
